# Carte interactive de la politique européenne

Ce site permet de visualiser, à date du 1er octobre 2026, les différents élections/nominations des pouvoirs exécutif et législatif de chaque pays européens ainsi que leur positionnement politique.

La carte à été faite avec Leaflet et la partie interactive à été faite à partir de ce [repo](https://github.com/georgique/world-geojson).
